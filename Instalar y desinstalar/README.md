# ¿Que es ros 2?

Robot operating system 2 es un marco de desarrollo para robots que proporciona todas las herramientas encesarias para crear apliaciones robóticas complejas. Aunque en su nombre este la frase "system" no es un sistema operativo como tal, sino un conjunto de librerías, protocolos y utilidades que facilitan:

- Comunicación entre sensores, actuadores y nodos de procesamiento
- La posibilidad de crear algoritmos para navegación, visión por computadora, manipulacion, contro, etc.
- Poder integrar hardware diverso en una arquitectura común.

ROS2 es un entándar para proyectos de robótica, desde robots moviles hasta brazos manipuladores y drones. Teniendo esto en cuenta estas son unas de las razones del por qué te recomiendo aprender ROS2:

- Comunicación robusta basada en DDS 
- Arquitectura modular: cada componente de tu robot sera un nodo independiente
- Ecosistema gigante: tienes miles de paquetes listos para usar
- Una comunidad activa: tendrás soporte, tutoriales y proyectos para cualquier nivel
- Y esta preparado para la producción
